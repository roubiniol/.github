# Roubiniol

Roubiniol builds **Sidearm**, a permissioned tool runtime for AI agents.

Every party, human or agent, is a principal with its own identity and permissions.
Every tool call passes one dispatch gate and lands in an audit log, and the model
behind an agent is interchangeable. Sidearm is self-hosted.

**Status:** the repositories are private while Sidearm gets ready for a public
release, under AGPL-3.0.
